# Project Details

### StackXchange - Resource Sharing platform⁠
#### React.js, Express.js, Firebase Authentication, Firestore, and Firebase Storage
* Built a full-stack resource sharing platform using React.js and Firebase.
* Implemented role-based authentication, protected routes, an admin dashboard, and real-time Firestore data handling.
* Developed features including file uploads, code editor integration, ratings & comments system, analytics charts, and responsive dark-mode UI.

### Ride Share - Car Pool application
#### Java, Spring Boot, React.js, SQL
* Integrated frontend React components with Spring Boot backend.
* Designed and implemented SQL-based relational database schemas for users, rides, and bookings.
* Wrote optimized SQL queries for data retrieval, filtering, and backend operations.

### Halifax Foodie - Serverless application
#### React.js, AWS, GCP
* Developed a full-stack application with React.js, integrated with AWS and GCP for seamless performance.
* Conducted cross-browser testing, achieving consistent UI performance across major platforms.

### Digi Soul - Tech community application
#### React.js, Node.js, Express, MongoDB 
* Built a single-page application with React.js and a robust back-end with Node.js and Express.js, achieving a 10% reduction in response time.
